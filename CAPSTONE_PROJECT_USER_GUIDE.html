2. Proposed Solution & Architecture

Traditional Antivirus (AV) scans binary files on disk against known malware hashes (MD5, SHA-256). However, in Living-off-the-Land (LOLBin) attacks, attackers execute code directly through legitimate, Microsoft-signed utilities:

  • powershell.exe (PowerShell)
  • wmic.exe (Windows Management Instrumentation Command-Line)
  • certutil.exe (Certificate Management Utility)

Because these binaries are core Windows utilities, antivirus software cannot delete or quarantine them without corrupting the operating system.

Our Engineered Solution:

We built a Full-Stack Behavioral Detection Web Application. Instead of inspecting disk files, our Java Spring Boot detection engine evaluates process creation audit logs (command-line parameters, parent processes, execution flags) against deterministic behavioral heuristic rules. It maps matched events to standardized MITRE ATT&CK Enterprise Techniques, persists sessions in MySQL (with automated H2 in-memory fallback), and provides a clean, responsive React (Vite) Analyst Dashboard.

7. Top Viva Voce Questions & Answers

Q1: What is a Living-off-the-Land Binary (LOLBin)?

Answer: A LOLBin is a legitimate, pre-installed operating system utility (e.g., powershell.exe, wmic.exe, certutil.exe) that has legitimate administrative purposes but can be abused by adversaries to execute malicious actions, evade antivirus, or download secondary payloads without introducing untrusted binaries.

Q2: Why does signature-based antivirus fail against fileless attacks?

Answer: Signature-based antivirus checks file hashes (MD5, SHA-256) on disk. In a fileless attack, the executable being launched is the authentic, Microsoft-signed binary. The binary's hash is completely clean, so traditional antivirus scanners have no malicious file to block.

Q3: How do your detection rules prevent false positives on legitimate admin commands?

Answer: The engine does not flag a process simply because of its executable name. It requires specific combinations of behavioral evasion parameters. For instance, standard commands like powershell.exe Get-Process contain no stealth flags and produce zero alerts. Only anomalous combinations (such as -ExecutionPolicy Bypass combined with -WindowStyle Hidden and -EncodedCommand) trigger high-severity alerts.

Q4: What is the MITRE ATT&CK framework and why is it mapped?

Answer: MITRE ATT&CK is a globally recognized knowledge base of adversary tactics and techniques based on real-world threat observations. Mapping our detections to MITRE technique IDs provides Security Operations Center (SOC) analysts with standardized threat intelligence context regarding the attacker's tactical objectives.
